# SCIPP SOC Analyst Xternship

## Overview

This repository documents my work completed during the SCIPP SOC Analyst Xternship. Throughout the externship, I perform hands-on cybersecurity activities including vulnerability assessments, security investigations, reporting, and defensive security operations.

The goal of this repository is to demonstrate practical SOC Analyst skills through real-world lab exercises and professional documentation.

---

## Objectives

- Develop hands-on SOC Analyst experience
- Perform vulnerability assessments using industry tools
- Create professional security reports
- Practice security analysis and remediation planning
- Document technical findings for portfolio development
